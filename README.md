A one-image front page summing up the world's news of Monday, 23 November 2026: COP31 ends with no deal in Antalya, Iran hits Bahrain, Ukraine sinks a Russian ship in Libya, Russian strikes kill in the Kyiv region, Asian chip stocks tumble, and Mexico captures a cartel chief.

## Run it

```sh
python3 draw.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`draw.py` draws the 1024x1024 front page to `entry.png` with Pillow; `main.ts` copies it to `/output/entry.png`.
